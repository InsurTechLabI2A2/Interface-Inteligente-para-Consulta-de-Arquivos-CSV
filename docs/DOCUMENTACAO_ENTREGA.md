# Documentação da entrega

Este diretório acompanha a solução final do Desafio 4.

- `GUIA_DE_TESTE.md`: passos para instalação, teste automatizado, demonstração manual, uso dos dados reais e ativação opcional do modelo.
- `documento_estado_anterior.docx`: análise dos arquivos originalmente recebidos, incluindo pontos fortes, problemas e riscos de entrega.
- `documento_estado_atual.docx`: descrição da solução montada agora, seus componentes, decisões e validações.
- `comparativo_entregas.docx`: comparação objetiva entre a versão recebida e a versão final.

O PDF técnico principal está na raiz como `relatorio_tecnico_desafio4_final.pdf` e o código-fonte compactado como `desafio4_entrega_final.zip`.
